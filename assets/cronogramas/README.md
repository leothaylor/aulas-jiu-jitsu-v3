# Artes de programação semanal do Studio TRION

Esta pasta já está preparada. **Não altere HTML, CSS nem JavaScript.**

Faça upload das artes originais neste diretório:

- trion-segunda.jpg
- trion-terca.jpg
- trion-quarta.jpg
- trion-quinta.jpg
- trion-sexta.jpg

Os arquivos também podem ser em **.png** ou **.webp**, com o mesmo nome-base:
por exemplo, trion-segunda.png ou trion-segunda.webp. A prioridade de leitura
é JPG, depois PNG, depois WEBP.

Use exatamente os nomes indicados, em minúsculas, sem acentos e com a extensão verdadeira
do arquivo. Não adianta renomear um PNG para JPG sem convertê-lo.

**Como enviar:** acesse esta pasta no GitHub → Add file → Upload files → arraste
os arquivos → Commit changes. O GitHub Pages irá publicar automaticamente.

O carrossel carrega somente os dias que já tiverem arte. Se enviar apenas
segunda e quarta, exibe somente os dois. Se nenhuma imagem existir, mostra
uma foto real da TRION e o site continua funcionando.

Ele gira automaticamente em intervalos de ~6,5 s, com setas, marcadores e swipe
no celular. O movimento é interrompido no hover, foco, fora da tela ou quando
o usuário prefere movimento reduzido.

**Importante:** são os horários gerais da TRION, não necessariamente a turma
do Leo. Os horários das aulas do Leo ficam fixos no bloco informativo da página.
